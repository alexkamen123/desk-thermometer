# 玩法路线图（尚未实现）

以下是基于板载硬件的构想，不是已实现功能或开发排期。当前温度牌不调用大模型。

| 玩法 | 效果 | 要增加什么 | 取舍 |
|---|---|---|---|
| 小熊换装与节日彩蛋 | 节日帽子、生日祝福、周末休息熊 | 日期规则和本地点阵 | 容易接入，保持低频刷新 |
| 手机留言牌 | 开会中、稍后回来、今日一句 | 留言入口与过期规则，中文字库或远端渲染 | 无需持续联网 |
| 专注计时器 | 剩余分钟＋小熊，结束回温度牌 | 旋钮输入、计时状态、分钟级刷新 | 适合分钟，不适合秒针动画 |
| 下班倒计时 | 还有42分钟，熊先坚持一下 | 工作时段、周末规则、单独页面 | 不覆盖原有温度请求 |
| 天气与带伞提醒 | 今天带伞、室外天气 | 数据源、位置设置、联网缓存 | 显示数据更新时间，离线可降级 |
| 温湿度日记 | 今日最高最低、24小时曲线 | 采样缓存，可选TF卡 | 装壳和板子发热影响读数 |
| 翻面换页 | 翻转后切到待办页 | IMU驱动、动作防抖 | 低功耗动作唤醒需验证 |
| 按键语音便签 | 按住说一句，生成待办 | 音频驱动和语音识别服务 | 功耗与复杂度高，适合主动按键触发 |
| AI每日一句 | 每天生成轻松、不冒犯的文案 | 服务端生成、缓存、内容约束 | 密钥放服务端，模型不决定温度阈值 |

建议优先做：**节日彩蛋 → 手机留言 → 专注/下班计时**，适合墨水屏静态、低频显示特点。每种模式都应能明确返回温度页。

硬件依据：[微雪官方文档](https://docs.waveshare.com/ESP32-S3-ePaper-3.97)。这块板有800×480墨水屏、Wi-Fi/BLE、温湿度传感器、RTC、旋钮、六轴IMU、麦克风/音频与扬声器接口、TF卡槽。硬件支持不等于当前固件已启用；云端语音/大模型不在板上直接运行。
