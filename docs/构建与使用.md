# 构建与使用

## 硬件

微雪ESP32-S3-ePaper-3.97，16MB Flash、8MB OPI PSRAM、800×480屏幕。本机使用1500mAh/3.7V电池。扬声器不是当前静默温度牌的必需品，TF卡、旋钮、IMU、音频功能尚未启用。

板卡参数与编译命令见README。首次刷机前自行保留出厂固件备份，勿公开备份文件；它可能包含网络凭证。

## 刷入

先连接数据线并确认自己的端口，不照抄其他人的串口设备名：

```sh
arduino-cli board list
arduino-cli upload --verify --port YOUR_PORT --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc,FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi --input-dir work/build src/desk_thermometer
```

USB在深睡时可能消失；按BOOT唤醒后再操作。必要时按官方说明进入下载模式（上电时按住BOOT），不要把运行中的配网长按与下载模式混淆。上传成功应进一步确认应用启动和真实画面，不以hash校验代替运行验收。

## 手机设置

1. 未保存网络时冷启动显示Wi-Fi Setup；以后换网，在运行/深睡中按住BOOT直至该页面出现再松手。
2. 手机连接屏幕上的TempSign热点，输入新的8位数字密码，访问 http://192.168.4.1 。热点没有互联网是正常的。
3. 页面自动扫描附近2.4GHz网络，点选名称，输入密码，点连接并保存。只支持普通密码网络，一次保存一个。
4. 网络校时成功后返回温度牌；若失败，确认手机日期正确后使用手机时间。
5. 点网页返回，或再短按BOOT并松手退出；5分钟后也会自动退出。换网可能导致手机短暂断开热点，重连后重新打开页面。

## 修改文案与测试

生成点阵需要Python/Pillow及可用字体。默认使用macOS系统字体；不分发字体文件。

```sh
python3 -m venv work/venv
work/venv/bin/pip install -r requirements-dev.txt
work/venv/bin/python src/tools/gen_assets.py
work/venv/bin/python src/tools/gen_weekday_assets.py
python3 src/tests/test_firmware.py
python3 src/tests/test_network_policy.py
python3 src/tests/test_clock_write.py
python3 src/tests/test_weekday_theme.py
python3 src/tests/test_portal_button.py
work/venv/bin/python src/tests/render_weekday.py
```

主机测试使用clang++。生成脚本和测试的跨平台字体路径需要自行适配。当前请求副句由request_message控制、阈值由request_min_c控制。修改后重新编译烧录才生效；手机页面尚不能编辑文案。

## 已知边界

- TIME UNSET表示RTC数据无效或通信失败，日期不可信时回退周一图案。完全断电后不保证保时。
- 日期切换发生在下一次采样刷新，不是午夜精确到秒切图。
- 180秒为休眠时间，刷新和偶尔联网会使画面间隔稍长。
- Wi-Fi常亮会使板子发热，刚退出配网的读数不宜立即当作稳定室温。
- PWR精确开关机手势未作为本项目统一承诺；参考官方板卡文档。
- 本地NVS存储的网络凭证未加密；不要上传整片Flash镜像。

官方资料：[板卡说明](https://docs.waveshare.com/ESP32-S3-ePaper-3.97)、[USB深睡说明](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-guides/usb-serial-jtag-console.html#sleep-mode-considerations)。
